Deskripsi Repository: Repository ini adalah tempat saya menyimpan hasil dan catatan dari workshop "From AI to GitHub: Building with AI, Managing Change with GitHub" Isinya ada proyek kecil yang saya buat dengan bantuan AI.

Tujuan Repository: Latihan langsung alur kerja Git dan GitHub: git init, git add, git commit, git push; dan jadi catatan belajar yang bisa saya buka lagi kapan saja, terutama soal cara menulis prompt AI yang baik dan cara memakai Git.

Rangkuman: Prompt itu adalah Instruksi atau masukan yang kita kasih ke AI supaya menghasilkan sesuatu. Prompt engineering adalah cara menyusun instruksi supaya jawaban AI tepat, relevan, dan layak dipakai. Konteks itu kunci, tanpa konteks: akan terlalu singkat, hasilnya bisa melenceng). Dengan konteks: menjelaskan tujuan, siapa penggunanya, fitur yang dibutuhkan, batasan teknis, dan format hasil yang diminta. Struktur prompt yang bagus ada 4 bagian: Role, Task, Context dan format. Git = alat pencatat perubahan di komputer, GitHub = tempat menyimpannya di internet. Tiga area kerja di Git: Working directory, Staging area dan Git directory (repository).

Poin-poin penting:
1. Prompt yang jelas = hasil yang lebih baik.
2. Git dan GitHub itu beda. Git adalah alatnya, GitHub adalah tempat penyimpanan online.
3. Nama origin hanya boleh didaftarkan sekali. Kalau muncul error "remote origin already exists", artinya remote sudah ada.
4. Repo baru sebaiknya dibuat kosong (tanpa centang README) kalau proyeknya dibuat dulu di komputer, supaya push pertama tidak bentrok.
5. SSH key membuat koneksi ke GitHub lebih aman dan praktis, karena tidak perlu mengetik login terus.
6. Hasil AI tetap harus dicek dan diuji.
